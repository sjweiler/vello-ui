# Changelog

All notable changes to VUI are documented here. The project follows Semantic
Versioning after the initial `0.1.0` release.

## 0.1.0 - 2026-10-10

- Added the renderer-neutral retained widget runtime and application model.
- Added Vello rendering, Parley/Fontique shaping, and AccessKit semantics.
- Added the multi-window Winit desktop host and lifecycle runner.
- Added replaceable platform services and the Linux XDG portal/D-Bus backend.
- Added session persistence, resources, background tasks, and deterministic harnesses.
- Added GPU visual regression testing with fixed Latin and Arabic font fixtures.
